# Supplementary Data for Cancer-Associated Histone Mutations Perturb Nucleosome Dynamics beyond Energetically Important Sites

This repository contains supplementary data and analysis scripts for the study.

## Repository Structure

- [Source_data](./Source_data/): Raw and processed source data from the study
- [Simulations_set_up](./Simulations_set_up/): Parameter files and input configurations for running simulations
- [Scripts_for_analyses](./Scripts_for_analyses/): Scripts used for data analysis and figure generation

## Data Availability

Simulation trajectories are deposited in the Science Data Center (SciDC), Nanjing University:

<https://scidc.nju.edu.cn/records/xs1wj-a4a27>
